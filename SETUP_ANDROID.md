# Android setup (one time)

The Dart code is ready. The `android/` folder is generated by Flutter, then
needs three small edits.

## 1. Generate the Android project

Run inside the `pockettally` folder:

```
flutter create --org com.lumio --project-name pockettally --platforms android .
flutter pub get
```

This keeps the existing `lib/` and `pubspec.yaml` and adds `android/`.

## 2. AndroidManifest.xml

File: `android/app/src/main/AndroidManifest.xml`

Add these two lines inside `<manifest>`, above `<application>`:

```xml
<uses-permission android:name="android.permission.INTERNET"/>
<uses-permission android:name="android.permission.REQUEST_INSTALL_PACKAGES"/>
```

Also change `android:label="pockettally"` to `android:label="PocketTally"`.

`INTERNET` is used only for the "Check for updates" button.
`REQUEST_INSTALL_PACKAGES` lets the app open the installer for the new APK.

## 3. Release signing

Updates only install over the old app if every release is signed with the
same key. Create the key once and keep it safe (never commit it):

```
keytool -genkey -v -keystore upload-keystore.jks -keyalg RSA -keysize 2048 -validity 10000 -alias pockettally
```

Back up `upload-keystore.jks` and its passwords somewhere private.

Then edit `android/app/build.gradle.kts`:

1. At the very top of the file add:

```kotlin
import java.util.Properties
import java.io.FileInputStream

val keystoreProperties = Properties()
val keystorePropertiesFile = rootProject.file("key.properties")
if (keystorePropertiesFile.exists()) {
    keystoreProperties.load(FileInputStream(keystorePropertiesFile))
}
```

2. Inside the `android { ... }` block add:

```kotlin
signingConfigs {
    create("release") {
        keyAlias = keystoreProperties["keyAlias"] as String?
        keyPassword = keystoreProperties["keyPassword"] as String?
        storeFile = keystoreProperties["storeFile"]?.let { file(it) }
        storePassword = keystoreProperties["storePassword"] as String?
    }
}
```

3. In the existing `buildTypes { release { ... } }` block, replace the
   `signingConfig` line with:

```kotlin
signingConfig = signingConfigs.getByName("release")
```

## 4. GitHub secrets (for the automatic build)

Repo -> Settings -> Secrets and variables -> Actions, add:

| Secret | Value |
| --- | --- |
| `KEYSTORE_BASE64` | the keystore file as base64 |
| `KEYSTORE_PASSWORD` | the keystore password |
| `KEY_PASSWORD` | the key password |
| `KEY_ALIAS` | `pockettally` |

On Windows PowerShell, copy the base64 text with:

```
[Convert]::ToBase64String([IO.File]::ReadAllBytes("upload-keystore.jks")) | Set-Clipboard
```

## 5. Release

```
git tag v0.1.0
git push origin v0.1.0
```

GitHub Actions builds the APK and attaches it to the release.
